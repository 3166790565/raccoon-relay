# 网关出站改写 + models.dev 模型元数据

## 新增功能

### 出站请求指纹脱敏

面板「设置 → 网关 · 出站改写」。按词表改写**发给上游的那份副本**，客户端发来的原文
与上游返回的响应都不变。

- 内置 14 条词表：Claude Code / Codex CLI 身份句、`x-anthropic-billing-header`、
  `cc_*=` 参数、DeepSeek Harness 提示词指纹等；每条只做最小改写，让上游的逐字指纹
  识别失配即可，不动你的项目规范与工具说明。
- 词表可在面板里增删改、导入导出、恢复内置；支持字面 / 正则两种匹配，
  正则删除规则可勾「重复清理」。
- 可按消息角色限定作用范围（system / developer / user / assistant / tool / function）。
- 可按提供商限定生效范围，留空 = 全部提供商。

### 开发者角色兼容

OpenAI 新版 API 用 `role:"developer"` 承载指令，部分 OpenAI 兼容上游不认识这个角色，
会直接 400。开启后转发前把它归一为 `"system"`：只改 role 字段本身，内容与顺序都不动。
默认开启。

### models.dev 模型元数据

用 [models.dev](https://models.dev) 补齐上游没声明的模型能力：上下文窗口、最大输出、
工具调用、图片、视频、是否支持思考，以及这个模型认识哪些思考档位。

- 优先级：**面板手工覆盖 > 上游声明 > models.dev > 未声明**。只填上游没声明的空位，
  不推翻上游已声明的值。
- 随包内嵌一份精简快照（573 条），离线、首次启动、访问不通时也有数据；
  开启后每 24 小时自动联网刷新，面板里也可以立即刷新。
- 关闭只停联网刷新，已经拿到的数据继续用。

## 面板

- 「设置 → 网关」新增两张卡片：
  - 出站改写：脱敏开关、词表编辑器、应用提供商多选、开发者角色兼容；
  - models.dev：开关、数据来源 / 收录条数 / 快照时间 / 最近刷新，以及「立即刷新」。
- 模型管理页每行显示能力来源（上游 / models.dev / 已覆盖），并列出该模型认识的思考档位。
- 映射弹窗的思考等级下拉只列该模型真实认识的档位，不再一律给通用表。
- 顺手修了 `/v1/models` 在别名与上游 id 相同时重复广告两条同 id 条目。

## 升级说明

- 直接替换二进制或拉新镜像即可，没有需要手工执行的步骤。
- 数据库无 schema 变更，旧库直接可用；新设置保存在 settings 表里，重启后保留。
- 原有环境变量全部兼容。新增四个（都只是首次启动的默认值，面板保存后以面板为准）：
  - `SANITIZE_ENABLE`（默认 true）
  - `SANITIZE_PROVIDERS`（留空 = 全部）
  - `DEVELOPER_ROLE_COMPAT`（默认 true）
  - `MODELS_DEV_ENABLE`（默认 true）
