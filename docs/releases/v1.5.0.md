## 更新日志

### 新增功能

**模型管理页**

- 新增「模型」页：按供应商列出上游模型，带上下文窗口、最大输出、能力徽章
  （工具调用 / 图片 / 视频 / 思考），支持搜索与供应商、状态筛选。
- **启停**：关掉一个模型后它不再出现在 `/v1/models`，直接请求也会被拒绝
  （404），不会再偷偷转发到上游。
- **别名映射**：给上游模型起一个稳定的对外名（`my-fast → deepseek-flash`），
  客户端用别名请求即可，后端随时换模型不用改客户端。别名会一起出现在
  `/v1/models` 里。
- **思考等级绑定**：可以给一条映射绑定默认思考等级；客户端显式指定时不覆盖。
- **能力位覆盖**：六个能力键（上下文 / 最大输出 / 工具调用 / 图片 / 视频 / 思考）
  都能按「提供商 × 模型」手动纠正，上游目录写错时不用改代码。
- **自定义模型**：上游目录里没有、但实际可用的模型 id 可以手动登记。
- **连通性测试**：每行一个「测试」按钮，直接向上游确认这个模型现在能不能用。
- 所有规则持久化，重启后仍然生效。

**日日新模型清单改为实时获取**

- 模型列表与路由不再用写死的 5 个模型，改为实时读取上游 `/v1/models`
  （10 分钟缓存），上游新上线的模型立刻可用，下线的自动消失。
- 拉不到实时清单时（没有可用账号、上游故障）才回落到内置快照。

**账号导出补全日日新凭据**

- 导出包现在同时包含小浣熊与日日新账号。日日新行额外带上控制台账号密码与
  登录票，导出后可以原样导入回来继续自动续期与重登。
- 「导出 JSON」支持只导出勾选的号：勾了就导勾选的，没勾就导全池。
- 空包直接拒绝，避免误以为导出成功。

### 修复

- 日日新账号导入后能登录但发不出请求（401）：建 API Key 打错了接口，
  改用控制台「API-Key 管理」实际使用的 `lite/console/v1/metered/api-keys`
  并带上 `key_type=API_KEY_TYPE_TOKEN_PLAN`。
- 日日新账号导入报「未能从授权页取到登录 challenge」：授权页的
  `login_challenge` 只在 302 跳转里出现一次，改用逐跳跟随而不是让 HTTP
  客户端自动跟到底。
- 账号锁定被误报成「账号或密码不正确」：上游对锁定返回的 reason 与
  「没有权限」相同，现在按文案区分，明确提示「账号被锁定，请 15 分钟后再试」。
- 停用模型返回的错误被标成 `upstream_error`，客户端会当 5xx 重试；
  现在按请求侧错误返回。

### 升级说明

- 纯代码修复与新增，无数据库改动，直接替换二进制或镜像即可。
- 之前导入失败、但账号密码正确的日日新账号，升级后重新导入即可。
- 模型管理是个新页面，不配置任何规则时行为与之前一致。
