## 更新日志

### 新增功能

**403 错误详情（号池页）**

- 号池页「限流」列里，**冷却中**和**需重登**的格子现在可点（右下角带「· 详情」），
  行末 `…` 菜单也新增了「错误详情」。点开后是一个弹层：
  - 账号当前状态、冷却原因、恢复时间、模型级限流明细；
  - 最近 5 次转发失败的完整现场：**上游返回码、接口路径、turn ID、上游请求 ID、
    请求摘要（模型 / 客户端 / 平台 / 设备指纹 / 会话）、脱敏后的响应头、原始响应体、处置动作**。
- 以前遇到 403，面板上只剩一句「HTTP 403」；真实原因（网关拦截码、风控文案、权限提示）
  几乎都在上游的响应头和响应体里，现在可以直接在面板上看到。
- `Set-Cookie`、`Authorization` 等可能携带凭据的响应头会被过滤，不会出现在面板上；
  响应体超过 3000 字符按字符截断，不会把汉字切坏。
- 弹层底部有「复制全部」和「在运行日志中查看」；后者会跳到运行日志并自动按
  「这个号 + 转发请求 / 号池冷却」筛好。
- 对应接口：`GET /api/accounts/{id}/errors`。

**运行日志：当前筛选一目了然**

- 已选中的来源和账号筛选，现在在筛选条下方显示成可点掉的标签（如「账号：xxx ×」），
  点 `×` 即解除该项。以前账号筛选藏在弹层里，看不出列表为什么只剩几条。

### 修复

- **错误详情按「最近发生」排序**：合并过的旧事件（首次发生很早、但一直重复到现在）
  会正确排在最前，点开看到的是最相关的那条，而不是早已过时的旧错误。
- **运行日志「重置」没生效**：在筛选弹层点「重置」后，已生效的账号 / 来源筛选没有被清掉，
  列表仍按旧条件展示。现在重置会真正清空并刷新列表。
- **点掉账号标签后又被加回来**：清除账号筛选后，筛选框里残留的值会在下次点「筛选」时
  把该账号重新加上。现在会一并清空。

### 升级说明

- 直接替换镜像或二进制即可，无数据库结构变更，无需任何手工操作。
- 已有的冷却号若是在本次改动之前产生的，事件表里没有它们的失败现场，点开只会提示
  「等下一次失败后再看」；号池跑起来后新出现的失败就都有完整详情了。
- 错误详情依赖新版面板与后端同时存在，请整体升级，不要只替换其中之一。
