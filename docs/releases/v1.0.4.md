## 更新日志

### 号池与冷却

- **选号策略收敛为两种**：`load_balance`（默认，负载均衡：在途请求最少 → 最久未用 → 积分多者 → 先到期者）与 `round_robin`（轮询）。
  旧的 `optimal` / `credit_first` / `manual` / `expire_first` 会自动按负载均衡处理，**无需改环境变量**。
- **429 改为只冷却「账号 × 模型」**：冷却阶梯 3 → 5 → 10 分钟，之后逐次翻倍（封顶 24 小时）；
  该模型调用成功即清零。账号本身保持在线，换模型照常可用。
  关闭模型级冷却后才退化为整号冷却 60 秒。
- **积分阈值冷却**：余额 ≤ 暂停阈值时暂停选号，≥ 解除阈值时自动恢复。面板「设置 → 冷却与积分阈值」可开关。
- **自动换号重试**可配置为「试完整个号池」，运行期热切换，不必重启。
- 402 积分耗尽仍冷却到次日 04:00，到点自动复活。

### 授权与签到

- **主动续期**：token 有效期 30 天，后台提前 3 天、每 6 小时扫描一次，冷门号不再静默过期；
  续期成功还会把被误判成「需重登」的号拉回在线。提前量/间隔/账号间隔均可在面板调整并热生效。
- 转发遇到 401 时先强刷一次再重放，刷得动就不再判 `relogin`。
- 403 不再一律打成「需重登」：风控/权限类 403 只做短冷却并换号。
- 刷新按账号单飞，并处理上游的并发刷新冲突（200822），避免凭据互相覆盖。
- **面板设置全部持久化**：选号策略、重试、签到时间、冷却阈值、续期、日志设置重启后仍然生效，
  环境变量只作为首次启动的默认值。

### 控制台

- **多标签页**：概览 / 号池 / 添加账号 / API Keys / 调用日志 / 运行日志 / 设置 / 版本更新，按需加载并记住当前页。
- **一键清理失效账号**：先预览清单再确认，删除前按最新状态复核，预览后被救回来的号不会被误删。
- **导入**：兼容 agent2api 的多供应商导出，自动过滤非小浣熊账号，并在面板提示过滤条数；
  重复导入只更新凭据，不再覆盖已有余额与账号状态。

### 运维

- **日志管理**：运行日志文件按大小/跨天轮转，按保留天数与数量上限清理；调用流水与签到记录按天分批清理；
  面板可查看文件清单、下载、立即清理。
- **一键更新**：面板直接检查并安装 GitHub Release 的新版本，强制 sha256 校验，原子替换并保留回滚备份。
  Docker 部署安装到数据卷 `/data/bin/relay`，重启、重建容器后仍生效；想回到镜像版本删掉该文件即可。
  裸机 Linux/macOS 自动重启；Windows 安装完成后需手动重启。

### 修复

- 模型冷却阶梯在冷却到期后总是从 3 分钟重来（选号时误删了失败链记录）。
- 402 积分耗尽的账号到期后无人复活，会一直卡在「积分耗尽」。
- Docker 下首次一键更新重启后仍跑旧二进制；全新部署时更新按钮不显示。
- 交叉编译的 Windows/macOS 发布版启动即报 `TZ 非法`（时区数据库未内嵌）。
- 重新导入 agent2api 包会把真实余额覆盖成「未知 -1」，并重置冷却/重登状态。
- 并发刷新（续期、签到、401 重试同时发生）后写库的旧凭据会把好号打成「需重登」。
- 积分「暂停阈值 = 解除阈值」时账号状态每分钟翻转一次。
- 关闭「自动清理」后重启仍会清理日志；单次清理 1000 条，积压永远追不上。
- 面板数字输入框清空会被当作 0 提交，可能静默关闭主动续期。

### 升级说明

- 直接替换镜像或二进制即可，数据库自动迁移，无需手工操作。
- 旧的 `POOL_STRATEGY` 值仍然可用（会自动归一为负载均衡）。
- 从 v1.0.1 起的镜像已内置入口脚本；若你的数据卷里没有 `bin/` 目录，首次点「一键更新」时会自动创建。
- Windows 裸机自更新完成后按面板提示手动重启即可。
