# 面板重做 + 外部渠道（AutoClaw / 码道）

## 面板

整体按 Agent2API 的设计语言重做，布局与配色都换了，功能与数据口径不变。

- **顶部标签改成左侧分组导航**：运行状态 / 账号与签到 / 转发能力 / 诊断 / 系统
  五组，选中项是主色实心块；窄屏自动收成图标栏，手机上是可滑出的抽屉。
- **明暗双主题**：浅色、深色、跟随系统三档，左下角切换，选择会被记住；
  首屏不会先闪一下再变色。
- **顶栏改为面包屑 + 状态胶囊**，底部新增网关运行状态灯（有冷却变黄、有异常变红）。
- **号池与日志页改为固定视口**，表头粘在顶部，表格自己滚动，换页不会停在半截。
- **报表图表随主题换色**：环形图、趋势图、热力图的配色统一，浅色下不再是深色底上的橙。
- 顺手修了号池空状态：一个账号都没有时，原来整块区域是空白，现在会提示去哪导入。

## 账号

- 号池页新增两个供应商分栏：🦾 AutoClaw、☁️ 码道。

- 号池页新增两个供应商分栏：🦾 AutoClaw、☁️ 码道。
- 「添加账号」新增两栏：
  - AutoClaw：粘贴 magpie/OpenCode 的登录记录，或国内站手机验证码登录；
  - 码道：粘贴插件导出的凭据 JSON（含 AK/SK/security_token/DPoP 私钥）。
- 也支持从 JSON 导入/导出：外部渠道账号的凭据整体进出，导入后可继续自动续期。

## 数据面

- 模型名带渠道前缀：`autoclaw/zai_auto`、`codearts/GLM-5.2`。前缀只用于路由，
  发给上游前剥掉；`/v1/models` 与流水保留带前缀的名字。
  - 这样做是因为 AutoClaw / 码道的模型名（glm-5.2、deepseek-*）与日日新重叠，
    仅凭名字无法判断该走哪台上游。
- 三条协议（OpenAI / Anthropic / Responses）都支持。
- 凭据临期自动续期；多副本下用 `ext_rev` 做 CAS，避免并发续期互相覆盖。
- 错误分类接入现有的冷却/退避/换号体系：
  - 额度用尽 → 整号冷却到下一次签到；
  - 临时凭据过期 → 续期后重试一次；
  - 封号 → 标记需重登；
  - 请求侧错误（图片、超长工具名、stop）→ 400，不冷却账号。

## 签到与额度

- AutoClaw：`daily_signin`，并在签到前调一次 `user-info` 领取登录活动奖励。
- 码道：`/v1/ops/delivery` → `claim` → `confirm`，普通签到与赛事附带的每日签到都会领。
- 额度查询接入「查余额」按钮与定时签到后的自动同步：
  - AutoClaw 显示积分余额；
  - 码道显示「剩余 / 总量」积分桶，以及免费日额度。

## 设置

号池页与「设置」页新增：

- 外部渠道上游地址（五项），留空使用内置默认值；面板可改、重启保留，
  与环境变量 `AUTOCLAW_*_BASE` / `CODEARTS_*_BASE` 的关系仍是「面板优先」。
- 地址校验：必须 http(s)、不带用户名密码/查询串/片段；任一项非法整体拒绝。

## 升级说明

- 直接替换二进制或拉新镜像即可，没有需要手工执行的步骤。
- 数据库为兼容升级：旧库启动时会自动补上外部渠道的凭据列，已有账号、冷却与设置不受影响。
- 原有的环境变量全部兼容；新增的 `AUTOCLAW_*_BASE` / `CODEARTS_*_BASE` 只是默认值，
  面板里改过的值优先，重启不会回退。
- 面板是打包进二进制的，升级后浏览器如果还是旧样式，强制刷新一次（Ctrl+Shift+R）。

## 已知限制

- AutoClaw 国际站的网页 OAuth 需要在官方白名单端口上起本地回调服务器，
  部署在容器里时不便完成，当前以「粘贴凭据」为主；国内站手机验证码可直接在面板完成。
- 码道国际站尚未用真实账号验证；国际站没有 opengw，因此没有免费额度与每日领取。
- 外部渠道的模型清单目前以各渠道内置快照 + 首次转发时的实时拉取为准。
